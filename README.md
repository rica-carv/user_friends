# user_friends
User friends plugin for E107.
Based on old Another Profiles plugin for E107 CMS system.
Still in beta development, but usable.
Use at own risk, i can't be responsable for any damage...

Requires two MANDATORY e107 modules (not plugins):
eadmin, donwload here: https://github.com/rica-carv/eadmin
ecore, donwload here: https://github.com/rica-carv/ecore

Just download and put them in the e107 plugins folder.
